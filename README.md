# SIRAE

## Sistema de Registro de Aspirantes a Enlaces Distritales y Municipales

SIRAE es un sistema desarrollado para gestionar el proceso de registro y selección de aspirantes a Enlaces Distritales y Municipales.

El sistema permite administrar de manera integral las diferentes etapas del proceso, desde el registro de las personas aspirantes hasta la revisión, validación y cumplimiento de los requisitos establecidos.

### Principales funcionalidades

- Registro de aspirantes.
- Captura y actualización de información personal.
- Registro de información académica, laboral y electoral.
- Carga y administración de documentación.
- Revisión y validación de documentos.
- Identificación de documentación pendiente o que requiere corrección.
- Seguimiento del cumplimiento de requisitos.
- Aplicación y registro de evaluaciones.
- Administración de usuarios, roles y permisos.
- Generación de constancias y reportes.
- Administración del proceso de selección de aspirantes.

### Tecnologías

- PHP
- Laravel
- Livewire
- MySQL
- JavaScript
- Vite
- Tailwind CSS

### Objetivo

Centralizar y facilitar la gestión del proceso de registro, revisión, validación y selección de aspirantes a Enlaces Distritales y Municipales, manteniendo un control organizado de la información y documentación correspondiente a cada aspirante.
